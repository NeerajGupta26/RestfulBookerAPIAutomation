# ⚙️ Getting Started

## Clone the Repository

```bash
git clone https://github.com/NeerajGupta26/RestfulBookerAPIAutomation.git
```

## Navigate to the Project Directory

```bash
cd RestfulBookerAPIAutomation
```

## Install Dependencies

```bash
mvn clean install
```

---

# ▶️ Running Tests

Run the complete test suite:

```bash
mvn clean test
```

Run a specific test class:

```bash
mvn test -Dtest=BookingTest
```

---

# 📊 Test Reports

The framework automatically generates interactive HTML reports using **Extent Reports** after every execution.

### Report Includes

- Test Summary
- Pass / Fail Statistics
- Execution Time
- Request & Response Details
- Exception Stack Trace
- Detailed Execution Logs
